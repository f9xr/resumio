# Changelog

All notable changes to Resumio are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/) and this project uses date based versioning.

## [1.2.0] - 2026-10-12

- Redesigned the interface to the `assets/md/DESIGN.md` design system.
- Added the animated Blurple to magenta gradient mesh over a deep indigo canvas.
- Switched to Hanken Grotesk (display) and Plus Jakarta Sans (body).
- Made the high-intent Export PDF action electric green.
- Replaced accent palettes with Blurple, Magenta and Violet.
- Removed all long dash characters across the project.
- Restructured assets under `assets/img` and `assets/md`; regenerated icons and the Open Graph image.
- Added README, CHANGELOG, CONTRIBUTING, LICENSE, 404.html, humans.txt, security.txt, .editorconfig, .nojekyll and .gitignore.

## [1.1.0] - 2026-10-11

- Replaced the remote AI call with a fully local, private analysis engine.
- Added SEO metadata, JSON-LD, sitemap.xml, robots.txt and a web manifest.
- Added the ATS score ring, job matches, company matches and writing tips.

## [1.0.0] - 2026-10-10

- Rebranded to Resumio with an ocean palette.
- Initial resume builder: profile, experience, education, skills, certifications and summary sections; PDF export; local auto-save; dark mode; mobile support.
